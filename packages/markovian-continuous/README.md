# markovian-continuous

This optional package implements a bounded exact family of continuous laws. A real law is a rational affine combination of compact rational uniform noises with explicit owners. The executable operations are affine pushforward, rational polynomial expectation, affine additive-noise kernel composition, joint moments, exact joint affine kernel materialization and support extrema, and finite affine conditioning.

The unreleased `pairedDifferenceReport` compares the coordinates of one existing exact joint law: means, variances, covariance, expected difference, difference variance, independent-marginal baseline, signed excess and LT/EQ/GT comparison. One operation-wide ledger covers structural preflight, five moments and all twelve derived work units. It checks work before arithmetic, saturates rejected counts at limit plus one, bounds discarded rational intermediates, and returns no partial report. Public accessors cannot update or recompute the opaque report. `(U,U)` has zero difference variance; `(U,1-U)` has covariance -1/12 and variance 1/3, worse than the independent baseline 1/6. This does not add trajectory/policy coupling or a universal variance-reduction guarantee. See the executable book lesson `paired-difference.md`; EL-03 remains Proposed; D-079's separate bounded acceptance does not accept paired-difference reporting.

Bivariate integration uses one cumulative meter. Separate limits bound raw expansion pairs and live canonical monomials. The report counts symbolic products, power merges, comparisons, coefficient operations, cancellations, canonical combinations, moment operations, and final sums. It also reports the largest intermediate rational size. The operation returns no report if a limit fails.

The joint affine kernel has two closed affine input coordinates and one owner table. Each row contains a compact interval and separate reward and successor coefficients. Duplicate owners fail before zero rows are removed. Owner numbers are local to one nominal kernel scope. A partial alpha-renaming preserves that scope. D-079 Gate B supersedes Gate A's retained-only renaming: membership, collisions, complete re-scoping, and work now cover every declaration, including zero rows. An empty mapping can re-scope only a declaration-free kernel. Materialization always returns `ExactJointLaw RealBorel RealBorel`. The other phantom parameters are nominal coordinate labels, not space witnesses. One table preserves shared-owner correlation while distinct rows remain independent. Exact extrema select endpoints by coefficient sign. Construction, materialization, support, and renaming use complete bounded preflight and deterministic reports. The historical Gate A fragment did not provide cross-kernel composition.

The unreleased `substituteLeftSuccessor` implements the [frozen D-079 Gate B contract](../../docs/plans/D079-LEFT-SUCCESSOR-SUBSTITUTION.md). It substitutes the left successor into both right coordinates and returns only the right reward and successor; the admitted left reward is lost, not accumulated. Complete injective requests either share every right declaration with an equal-law left declaration or freshen every right declaration to names disjoint from both full manifests. One combined ledger admits the count-only mapping spine and all reservations before derived tables. Private witnesses capture the actual operands. Complete zero-result sources and reservation-only original names survive privately. The sealed nominal result cannot be chained, re-scoped, or unpacked into a kernel or local owner. Its only observers are reporting, real-Borel materialization, and extrema. Both separately budgeted projections retain the complete historical rational maximum, including canceled intermediates and discarded left reward. D-079 is `Accepted` within its bounded, unreleased scope; see the [separate acceptance and evidence record](../../docs/DECISIONS.md#d-079-add-exact-joint-affine-continuous-kernels). This is not temporal reward accumulation, general composition, a category claim, disintegration, device evidence or a release.

Measurability is a syntax-directed obligation, not a run-time claim about callbacks. Rational affine real maps are continuous and Borel measurable. Compact uniform sources are Borel probability laws, finite products remain standard Borel, and each output is a finite affine projection. No public joint-kernel constructor accepts a function.

The tests use independent raw and multinomial symbolic oracles for shared and independent owners. They cover exact limits, one-below failures, failure precedence, duplicate monomials, hidden zero-owner duplicates, same-scope and complete-scope renaming, negative signed-owner support corners, and cancellation. One cancellation fixture has a discarded rational maximum larger than its retained zero. The tests also include deterministic accounting goldens and a bounded numerical differential fixture.

`ExactLaw` does not represent every measurable event. The package does not accept arbitrary Haskell functions as measurable maps, provide point conditioning, or provide continuous-to-continuous disintegration. See the repository book chapter `continuous-probability.md`.
